# Data audit: long-history XAUUSD 1-min file

Written by `research/vol_features_r2/audit_long.py`. Source `database/ohlcv_data/XAUUSD.txt`. Only rows before 2024-01-01 were read into the audit.

## File

- 6,971,972 rows before 2024, 2003-05-06 00:01:00 to 2023-12-29 21:58:00.
- Format: `TICKER,YYYYMMDD,HHMMSS,O,H,L,C,VOL`, one row per 1-min bar with at least one tick.
  The header line has stray text in front of it (`should contai<TICKER>...`), so it is skipped.
- Rows are not sorted as stored (monotonic: False). Duplicate timestamps: 1 (first kept). Bad OHLC rows: 1.
- **Timezone: UTC in every year where it can be identified.** 2020–2023 match the clean UTC parquet close for close with no shift (share of exact matches: 2020: 1.000, 2021: 1.000, 2022: 1.000, 2023: 1.000), so the parquet was built from this file. Earlier years: the hourly range profile correlates best with the UTC reference at shift 0 in both US-DST seasons, and the daily break sits at 21 UTC (US summer) / 22 UTC (US winter), which is 17:00 New York.
