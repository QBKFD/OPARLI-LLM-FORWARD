| # | Decision | Conservative because | Alternative |
|---|---|---|---|
| D1 | **The bull/bear debate is removed:** `agents/debate/`, the judges, `DebateConfig` and the `[debate]` infra section. `check_ref` moved to `agents/evidence.py`. The `debate_turns` table stays as history and isn't written. | "Replacing" means one code path, not two; nothing the owner wrote is touched. | Keep the debate code beside the discussion. |
| D2 | **Speakers are the voters with a `discuss` method** (the LLM agents) whose round-1 vote didn't abstain. Rounds are simultaneous, views are content only, and code agents and abstainers are shown as they are (AA7). | Mirrors the approved design; a stub or code agent can't take part by accident. | A configured list of speakers. |
| D3 | **The vote-change rule is pure code** (`agents/discussion/rule.py`). | D4 | **A directional vote needs at least one resolving non-`vote:` ref,** in round 1 and in the discussion. A restated vote that only cites `vote:` refs abstains as invalid, and the change rule then carries its previous vote. | "A vote: ref never counts on its own" holds for every vote, not only for changes. | Accept a restatement backed only by `vote:` refs. |
| D5 | **The discussion's skip reasons,** most basic first: no discussants in the graph, then an invalid `[discussion]`, then an invalid `discussion.md`, then everyone abstained in round 1. A skipped discussion is a `discussions` row with `rounds_run = 0`, and **both decisions are still stored** (`discussion` = Meta on the round-1 votes). | Every alert has the same two arms; why nobody spoke is always recorded. | Store only the blind decision when nobody speaks. |
| D6 | **Discussion vote rounds are numbered from 2** (round 1 is the blind vote). That is the number agents cite in `vote:<agent>:<round>`. | One round sequence per agent, as the votes table's key already allows. | A separate discussion-round column. |
| D7 | **Meta is pluggable, with no default rule.** `quorum_v0` (unchanged aggregator v0) and `fixed_meta_v1` (the legacy meta_decision, fixes 1–5, exact fractions, min 2 directional votes). Each rule's parameters are part of its version. No rule or an unknown rule gives `none` with the reason. The rule name and version are on every decision and enter the epoch. | The owner chooses the rule; a missing choice is visible, never filled in. | Default to `quorum_v0`. |
| D8 | **The agents test suite runs with a test `agents.toml`** (rule `quorum_v0`) through `$AGENTS_CONFIG`, set by an autouse fixture. Tests of the missing-config path unset it. | Code keeps no default rule; the graph tests state their rule. | A default rule in code for tests. |
