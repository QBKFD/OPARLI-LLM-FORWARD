# research/gex-feasibility

The study `research/gex_feasibility/`: is listed gold options positioning
big enough for a GEX level effect to be plausible? The rules are in its
[PREREG.md](../../research/gex_feasibility/PREREG.md), committed first, before
any code or data (`94c0b1a`). Decisions taken without the owner, each with
its alternative.

It reads no XAUUSD bars, no returns, and no price behaviour near strikes.
