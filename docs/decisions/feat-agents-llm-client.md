# feat/agents-llm-client (agents v2, job 3)

Built 2026-10-17, stacked on `feat/agents-prompt-config` (#19).

| # | Decision | Conservative because | Alternative |
|---|---|---|---|
| C1 | **`anthropic==1.11.0`** (2026-09-30), the newest release at least two weeks old, in a new `llm` extra. The lock was regenerated with the documented pip-compile command. It adds `anthropic`, `docstring-parser` 0.18.0 and `jiter` 0.17.0; **every existing pin is unchanged**, and neither new dependency needed a cap. | The repo's two-week rule; a reviewable lock diff (three packages). | The newest 1.15.0 (2 days old). |
| C2 | **The SDK is imported lazily**, in `agents/llm/anthropic_client.py` only. The package guard test now allows `anthropic` in that one file, checks the import is inside functions, and checks in a fresh interpreter that importing the graph and the LLM layer loads no SDK. | The boundary stays enforced, narrowed by one file. | Drop the guard. |
| C3 | **Our own retry loop**, with the SDK's `max_retries=0`: 1 + `llm.max_retries` attempts, capped exponential backoff (0.5 s … 8 s). Only timeouts, connection errors and 408/409/429/5xx are retried. An unexpected client exception isn't retried. | Every attempt is a ledger row with its request id, which the SDK's internal retries would hide. | The SDK's retries. |
| C4 | **No sampling parameters, no `thinking` field, no refusal fallbacks** (AA11). Effort is sent explicitly from the owner's config. | Each model's own default applies; one model per epoch. | Send `thinking: adaptive` (rejected by older models the owner might pin). |
| C5 | **Live mode reuses a cached response** for a byte-identical request, recorded as `cached = 1` with no cost. | No double spend; the same request gives the same answer. | Always call in live mode. |
| C6 | **The kill switch applies to live calls only.** Rerun mode never calls, so it keeps working while the switch is on. | Reruns stay reproducible during an incident. | Abstain in rerun too. |
| C7 | **The budget counts sent attempts** (attempt ≥ 1), not cache hits or rerun misses. It is reserved under a lock before sending, so parallel agents can't overshoot (tested with 20 threads). | The cap bounds real spend exactly. | Count every row. |
| C8 | **`llm_calls` references the snapshot hash**, not the run, because calls happen before the run row is written. `votes.call_id` links each vote to its row. | No foreign key that the write order would break. | Write the run row first. |
| C9 | **The answer is checked again in code** (fields, confidence in [0, 1], text lengths, ≤ 6 evidence items, refs through `check_ref`). The output schema leaves out bounds that structured outputs don't support. A directional vote needs a resolving ref. `check_ref` gains the `metric:` and `chart:` kinds. | It holds whatever the API enforces; nothing is guessed. | Trust the schema. |
| C10 | **Abstain order:** prompt → round-1 call settings → `[llm]` / `[budget]` → render → call → served model → stop reason → answer. The first problem is the reason. | One clear, deterministic reason per vote. | Collect every problem. |
| C11 | **A warning at build time** when (1 + max_retries) × timeout_s can exceed `node_timeout_s`; the node timeout then abstains first. | The owner sees the mismatch; behaviour stays safe either way. | Refuse to build. |
| C12 | **Cost is a list-price estimate** for known models (Opus 5.5, Sonnet 5.5, Haiku 5.5), and None for others or for a cache read without a known price. The price table never restricts which models can be used. | Visible spend without gating the owner's choice. | Refuse unknown models. |
| C13 | **`python -m agents.llm count-tokens`** makes one API call per agent (`count_tokens`, no generation). It is tested only with the fake client. | Real token counts for the owner's cost estimate; no network in tests. | Leave it out. |
| C14 | **Merge note:** after #15 (Studio) merges, `requirements/requirements-studio.lock` must be regenerated from the new `requirements/requirements.lock`. Its test requires every project pin to be present unchanged. | Flagged for the sync instead of editing #15's file here. | Edit #15's lock in this branch. |
